# 🐳 Estudos de Docker

Repositório dedicado ao aprendizado prático de Docker e Docker Compose, com exemplos, anotações, comandos, exercícios e projetos desenvolvidos durante os estudos de Sistemas Distribuídos.

## 🎯 Objetivos

- Compreender a arquitetura e os principais conceitos do Docker.
- Criar, executar e gerenciar containers.
- Baixar, construir e versionar imagens.
- Criar imagens personalizadas utilizando Dockerfile.
- Persistir dados utilizando volumes.
- Configurar redes para comunicação entre containers.
- Orquestrar aplicações utilizando Docker Compose.
- Desenvolver uma aplicação com múltiplos serviços.

## 🚀 Como começar

1. Instale o Docker de acordo com seu sistema operacional.
2. Verifique a instalação com `docker --version`.
3. Execute `docker run hello-world`.
4. Siga os laboratórios na ordem numérica das pastas.
5. Registre os resultados, erros e aprendizados de cada atividade.
